# UTS_PWEB_252410103082

# noiffee adalah aplikasi web pengelolaan coffee shop yang dibuat dengan Laravel versi 12 dan Tailwind CSS sebagai tampilannya. Pengguna login, lalu masuk ke dashboard berisi ringkasan kedai. Dari sana pengguna bisa membuka halaman pengelolaan (menu, stok, pesanan, karyawan) dan halaman profil. Username dari form login dikirim ke halaman lain lewat request parameter, dan data berupa array dari controller ditampilkan dengan @foreach.
